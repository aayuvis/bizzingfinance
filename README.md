# Bizzing Finance

Financial literacy for kids **8+** — the third app in the Bizzing family, after
[Bizzing Bee](https://github.com/aayuvis/Bizzing-Bee) (spelling, 8–15) and
[Bizzing India](https://github.com/aayuvis/bizzingindia.com) (culture & Hindi, 4–12).

**Currently concept-stage.** Docs only, no application code yet.

**There is a playable prototype** in [`app/`](app/) — a town called Bizzington with a wallet,
four jars, a Build Yard, a bank, an Exchange and three games. `cd app && python3 -m http.server 8080`.

Start here:

1. [CONCEPT.md](CONCEPT.md) — what it is, who it's for, the spine, the ladder, the cast.
2. [docs/02-the-world.md](docs/02-the-world.md) — **Bizzington**: the town, the daily letter,
   pay day, and what actually makes this fun rather than worthy.
3. [docs/01-tabs.md](docs/01-tabs.md) — the tab map: every tab, every shelf, what unlocks when.
4. [app/README.md](app/README.md) — how to run it, how it's built, what's still missing.
5. [CLAUDE.md](CLAUDE.md) — how to work in this repo and the hard rules.

> **One line:** kids don't learn money from a lesson — they learn it from decisions that cost
> something. So we give every child a town, a wallet, a budget, a bank and a portfolio that
> are entirely simulated and entirely theirs, and let the consequences land.
